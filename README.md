# Abdullah Qaasim-Falade — Portfolio

Personal portfolio for **Abdullah Qaasim-Falade** — Creative Technologist, Systems Architect, and Founder of [NIT7ER](https://nit7er.vercel.app) & [NIT7ER Academy](https://nit7er-academy.vercel.app).

## Stack

- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript 5
- **Styling:** Bespoke Vanilla CSS Editorial Architectural Design System (Light Limestone & Dark Obsidian themes)
- **Typography:** `Instrument Serif`, `Plus Jakarta Sans`, `JetBrains Mono` via `next/font/google`
- **Architecture:** Single typed data layer in `src/data/portfolio.ts` covering all 18 projects, NIT7ER essays, ventures, capabilities, and social channels

## Local Development

```bash
npm install
npm run dev
```

## Updating Content

Edit [`src/data/portfolio.ts`](src/data/portfolio.ts) to add new projects, essays, or social links (such as an X/Twitter handle).

## Deployment

Ready for zero-config deployment on **Vercel** or any Node.js hosting provider:

```bash
npm run build
npm start
```
